# Vimeo Showcase Downloader

Веб-приложение для пакетного скачивания видео из Vimeo showcase. Разворачивается на сервере через Docker Compose.

## Возможности

- Скачивание всех видео из Vimeo showcase по одной ссылке
- Поддержка showcase с паролем
- Прогресс скачивания в реальном времени (SSE)
- Скачивание файлов по одному или все сразу в ZIP
- Nginx reverse proxy для продакшена
- Ограничение одновременных загрузок

## Развёртывание на сервере

```bash
git clone <repo-url> && cd butch_vimeo_download
docker compose up -d
```

Приложение доступно на порту `80`. Откройте `http://<ip-сервера>` в браузере.

### Настройка

Переменные окружения (в `docker-compose.yml`):

| Переменная | По умолчанию | Описание |
|---|---|---|
| `MAX_CONCURRENT_JOBS` | `3` | Макс. одновременных загрузок |

Для HTTPS — добавьте сертификаты в nginx или поставьте перед ним Caddy/Traefik.

## Использование

1. Откройте приложение в браузере
2. Вставьте ссылку на showcase (`https://vimeo.com/showcase/...`)
3. Введите пароль, если showcase защищён
4. Нажмите «Начать скачивание»
5. Дождитесь завершения
6. Скачайте файлы по одному или нажмите «Скачать все (ZIP)»

## Архитектура

```
Browser  -->  Nginx (:80)  -->  Gunicorn + Flask (:5000)
                |                       |
                |                   yt-dlp (subprocess)
                |                       |
                +--- /downloads/ <------+
```

- **Nginx** — reverse proxy, отдаёт статику скачанных файлов
- **Gunicorn + gevent** — WSGI сервер, поддерживает SSE и долгие соединения
- **yt-dlp** — скачивает видео из Vimeo
- **ffmpeg** — объединяет аудио/видео потоки
